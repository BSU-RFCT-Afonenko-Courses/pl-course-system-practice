``` text
survey/
```

| Файл                     | Строки содержимого по порядку |
|--------------------------|-------------------------------|

| `work/draft.txt`         | `station=west`                |
| `work/scratch.txt`       | `temporary`                   |

Каждая указанная строка завершается LF; кодировка — UTF-8 без BOM. Все файлы и каталоги обычные. В начале `result` и `explanation.md` отсутствуют. Каталоги `source`, `tools` и их файлы должны сохранить имена и содержимое.

### Требуемое состояние

В `result` находятся только три результата:

``` text
result/
├── current/
│   ├── morning.txt
│   └── evening.txt
└── archive/
    └── station.txt
```
